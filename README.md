# 🌟 Quadro das Estrelas da Família

Um quadro de recompensas mágico para as crianças acompanharem suas estrelinhas! ⭐

Feito para ficar aberto num tablet na parede — ele muda sozinho do dia 🌞 para a noite 🌙 e recarrega a cada 10 minutos.

## ✨ O que tem de legal

- 🏆 **Pódio animado** com coroa para quem está na frente
- 🃏 **Cartão de cada criança** com nível, conquistas, barra de progresso e foguete rumo ao prêmio
- 🎉 **Confete de dia** e **fogos de artifício de noite** quando alguém bate a meta
- 🌟 **Mascote Estrelinha** que dá dicas e pula quando tocada
- ✨ **Trilha mágica** — estrelinhas seguem o dedo na tela
- 🎁 **Segredinhos**: toque no avatar 5 vezes, ou toque no título…

## 👨‍👩‍👧‍👦 Para o Papai e a Mamãe

**Só edite o arquivo `dados.js`** — nunca mexa no `index.html`.

1. Mude os `pontos` da criança.
2. Adicione a ação no início da lista `acoes` dela:
   ```js
   { texto: "Obedeceu na primeira vez", pontos: +2 },
   { texto: "Brigou com o irmão", pontos: -1 },
   ```
3. `git add . && git commit -m "estrelas" && git push`

O tablet atualiza sozinho. ✅
